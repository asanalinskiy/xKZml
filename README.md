# 🇰🇿 ҚазақСкрипт (QazaqScript) v1.0.0-ҰЛТТЫҚ

> **ҚазақСкрипт** — XML стандартында негізделген, шексіз кастомды тегтері бар және қатаң тілдік сүзгімен қорғалған ұлттық бағдарламалау тілі (DSL / Эзотерикалық тіл).

---

## 🚀 Ерекшеліктері (Особенности)

* **Шексіз синтаксис (XML-based):** Любой XML-тег становится валидной конструкцией. Хоть 100 000 кастомных тегов для квестов, конфигов или интерфейсов!
* **Қатаң Тілдік Сүзгі (Strict Mode & Language Barrier):** Жесткая проверка чистоты языка. Латиница, арабские символы, эмодзи и русские слова блокируются на корню.
* **Үндестік Заңы (Закон Сингармонизма):** Спецалгоритм проверяет гармонию гласных в корнях слов. Попытки обхода вроде `<databaseлар>` или `<printет>` отсекаются автоматикой.
* **Таза Python Движогі:** Никаких лишних Node.js CLI и библиотек — быстрый монолитный парсер AST-дерева и интерпретатор на чистом Python.
* **`.qs` Кеңейтілімі:** Собственный формат файлов для кода и конфигураций.

## 💻 Код мысалы (`бағдарлама.qs`)

В `.qs` файлах **нет место заимствованным прологам** вроде `<?xml...?>` — только чистые казахские теги:

```xml
<ҚазақСкрипт>
    <!-- Айнымалылар -->
    <айнымалы атау="аты">Асанәлі</айнымалы>
    <!-- Менiӊ атым Асанәлi -->
    <айнымалы атау="балл">95</айнымалы>

    <жаз>Сәлем, $аты!</жаз>

    <!-- Шартты тексеру -->
    <егер шарт="$балл > 80">
        <жаз>Құттықтаймыз! Сіз үздік нәтиже көрсеттіңіз! 🏆</жаз>
    </егер>

    <!-- Цикл -->
    <қайтала саны="3">
        <жаз>Алға, Қазақстан! 🇰🇿</жаз>
    </қайтала>

    <!-- Кастомды бесконечный тег (Шексіз XML) -->
    <ОйынКвесті деңгей="10" атау="Айдаһар">
        <жаз>Квест орындалуда...</жаз>
    </ОйынКвесті>
</ҚазақСкрипт>

```

## 🛠 Іске қосу (Запуск)

Код напрямую исполняется через главную точку входа `qazaq.py`:

```bash
# Обычный запуск .qs файла
python qazaq.py бағдарлама.qs

# Запуск со строгой проверкой чистоты казахского языка (Strict Mode)
python qazaq.py бағдарлама.qs --строгий

```

## 🛡 Қауіпсіздік және Бағдарламалау Ережелері

| Тексеру түрі | Рұқсат етілген (Allowed) | Бұғатталған (Banned) |
| --- | --- | --- |
| **Әліпби** | Қазақ кириллицасы (`А-Я`, `Ә`, `Ғ`, `Ң`, `Ө`, `Ұ`, `Ү`, `Һ`, `І`) | Латиница (`a-z`), Арабша, Эмодзи |
| **Тегтер мен Атрибуттар** | `<айнымалы атау="x">` | `<variable name="x">`, `<айнымалы name="x">` |
| **Лайфхактар (Суржик)** | `<деректерБазасы>` | `<databaseлар>`, `<датабаселар>`, `<printет>` |
